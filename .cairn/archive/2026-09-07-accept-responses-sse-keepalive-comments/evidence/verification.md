# Verification

## Root cause and change

A retained live capture showed OpenRouter emitting SSE comment keep-alive records (`": "` lines) before and between real events when generation is slow.
The parser rejected each comment-only record as `Malformed`, so slow live responses failed intermittently while fast ones succeeded.
A fresh live capture caught the failing bytes: HTTP 200, first parse failure at line two, identity `7a368f858420384c11d3607e5beda240cb0a493aec08b20cc6e51d32ab87c975`.

The parser now skips a record whose every line starts with the comment prefix.
Each skipped record still consumes one event-count unit and its bytes stay inside the event bound.
Comments mixed with data or event fields, duplicate fields, unknown lines, sequence and identity checks, the guarded `[DONE]` marker, and final completeness checks are unchanged.

Branch `fix/responses-sse-keepalive-20260907` is based on Animus `main` at `db82f977a0c33c2217d9ede63e14c932d2376164`.
