# Fake-backed headless dogfood shell

The dogfood shell evidence rung is **fake-backed integration**. The reusable runtime accepts a bounded prompt descriptor, policy profile, model capability, optional tool metadata, output contract, and noninteractive mode, then drives deterministic fake model/tool services through typed admission and safe receipt projection.

This evidence proves the request/admission/event/receipt path only. It does **not** claim live-provider execution, credential discovery, network dispatch, default product tools, persistence, daemon attach, TUI dogfood, plugin runtime behavior, production readiness, or Clankers parity.

Next validation rungs are packaged headless shell execution and optional live-provider checks, each requiring separate receipts and non-claim review.
